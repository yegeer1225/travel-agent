# --- Agent 内核 -------------------------------------------------------------
#
# 🔴 这三个必须写死版本，不要改回 >= 或去掉版本号。
#
#    原因：langgraph-checkpoint-mysql 是【第三方包】（单人维护，非 langchain-ai 官方），
#    它声明的依赖是 `langgraph-checkpoint>=2.1.2` —— **没有上界**。
#    对比两个官方包：langgraph-checkpoint-sqlite / -postgres 都写死 `<5.0.0,>=4.1.0`。
#    无上界的后果：pip 在任何升级场景下都认为"满足"，**不会拦任何不兼容**，
#    坏了也只能等运行时报错才发现（而且往往报在 M5 跑图的时候）。
#
#    改这三个版本之前，先跑兼容性探针（30 秒出结论）：
#        cd backend && ../.venv/Scripts/python.exe scripts/check_checkpoint_mysql.py
langgraph==1.2.11
langgraph-checkpoint==4.2.0
langgraph-checkpoint-mysql==3.0.0

# --- MySQL 驱动 -------------------------------------------------------------
# 两个都要：PyMySQL 走同步（建表 / 脚本 / 评测），aiomysql 走异步（FastAPI 里用）。
# 连接串前缀不一样，写错了连不上：
#     mysql://           → PyMySQLSaver
#     mysql+aiomysql://  → AIOMySQLSaver
PyMySQL==1.2.0
aiomysql==0.3.2

# --- LLM --------------------------------------------------------------------
# ⚠️ langchain-openai 会剥掉 DeepSeek 的 reasoning_content 字段，
#    带 tools 的请求必须关思考（LLM_THINKING_TOOL=disabled），详见 .env 里的注释。
langchain-core==1.6.3
langchain-openai==1.6.2

# --- 数据契约 ---------------------------------------------------------------
# schemas.py 是三方共用的事实源，docs/types.ts 由它自动生成。
# 动 pydantic 大版本前先重跑：
#     python backend/scripts/gen_ts_types.py && tsc --noEmit docs/types.ts
pydantic==2.13.5

# --- 配置与 HTTP ------------------------------------------------------------

# python-multipart：multipart/form-data 解析（M9 头像上传），版本 2026-09-16 实测

# Pillow：头像四道闸门（真实解码 + 解压炸弹防护 + 强制重编码 512×512 WebP，D29）

# --- 测试 -------------------------------------------------------------------
