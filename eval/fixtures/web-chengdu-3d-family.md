## 原文正文（行程相关段落，逐字保留）

有人说，成都适合反反复复来。一半是青砖黛瓦、盖碗茶、掏耳朵的老成都；一半是熊猫、火锅、潮牌、夜景的新成都。成都是一座现代摩登与市井烟火完美融合的城市，有着看不完的熊猫滚滚和吃不够的地道美食。暑假带娃逛成都、看熊猫🐼，不赶行程，不特种兵，慢悠悠吃，慢悠悠逛，才是成都正确的打开方式。

📌 行前必看
1. 首选到站：成都东站车次最多，交通最便利，春熙路、太古里，去往各大景点换乘超方便，外地游客优先选这里
2. 机场出行：先选双流机场（离市区近）
3. 门票预约：🎫 三星堆和一些热门博物馆需提前抢票，🐼 熊猫基地务必早去：7:30开园就到，如果不赶早去，可能连熊猫屁股都看不到哦。
4. 饮食注意：成都口味偏麻辣重油，如果不能吃辣，千万强调"微辣"或备好肠胃药。

🍽️ Day1 老成都烟火｜宽窄巷子→人民公园→武侯祠→锦里→火锅

上午｜宽窄巷子
• 老成都街巷，青瓦灰墙、木门雕花，随手拍都是古风大片。
• 玩法：宽巷子喝茶、窄巷子逛文创、井巷子拍砖墙。
• 小吃：三大炮、糖油果子、蛋烘糕，浅尝即可。

下午｜人民公园 → 武侯祠
• 人民公园（免费）：本地人日常聚集地。鹤鸣茶社点一杯盖碗茶+掏耳朵，体验"巴适"慢生活
• 武侯祠：唯一君臣合祀祠庙，红墙竹影超好拍，三国迷必打卡

晚上｜锦里古街 → 火锅
• 锦里：晚上亮灯后最美，红灯笼、古色古香，氛围感拉满。
• 小吃：张飞牛肉、凉粉、糖油果子

🐼 Day2 顶流萌主+潮拍｜熊猫基地→春熙路→太古里→IFS→九眼桥

清晨｜大熊猫繁育研究基地（必打卡）
• 7:30开园就冲南门，直奔幼年别墅，看花花、和叶干饭卖萌。
• 观光车必买，园区大，走路累瘫。
• 穿搭：浅色衣服，拍照干净出片。

下午｜春熙路 → 太古里 → IFS
• 春熙路：成都最繁华商圈，潮人聚集地，逛吃逛买。
• 太古里：传统青瓦+现代玻璃，潮牌、方所书店、网红墙，超好拍
• IFS爬墙熊猫：7楼天台拍正面，成都地标，必打卡。

晚上｜九眼桥夜景
• 成都夜生活天花板，酒吧街沿河，吹晚风、小酌、看锦江夜景，氛围感拉满。

🌿 Day3 古韵+citywalk｜杜甫草堂→四川博物院→文殊院→玉林

上午｜杜甫草堂 → 四川博物院
• 杜甫草堂：诗圣故居，竹林幽深、红墙青瓦，汉服拍照绝美
• 四川博物院：看张大千真迹、三星堆复刻，了解古蜀文明

中午｜文殊院
• 千年古刹，红墙竹影超出片，素斋+椒盐酥必吃

下午｜玉林citywalk
• 成都最有烟火气的片区，老小区、梧桐街、小酒馆、随便走都舒服。
• 打卡：玉林西路小酒馆

💡 暖心小贴士
1. 热门景点提前线上预约，免去现场排队烦恼
2. 成都美食偏麻辣，不吃辣提前叮嘱店家调整口味
3. 游玩不用赶行程，放慢节奏，才算读懂这座城市
4. 夏季出行做好防晒，舒适穿搭轻松游玩
